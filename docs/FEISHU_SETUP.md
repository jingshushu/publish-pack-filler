# 全平台半自动发布助手 · 飞书直连、跨设备迁移与本地寻址指南 (v2.0.0)

`v2.0.0` 采用 **「插件内置纯 JS 飞书直连引擎（必选核心） + 本地纯标准库文件寻址小服务（可选增强）」** 双层解耦架构：
1. **零外部依赖直连飞书/Lark 多维表**：所有排期防撞雷达、发前作品关联、发布时间/标题/话题回写、以及 **云端兜底文案拉取** 均在 Chrome 插件内部直接通过飞书 OpenAPI 完成——**换任何电脑无需安装外部 CLI 或配置系统钥匙串**，哪怕不开本地 Python 脚本也能独立完成填表与飞书同步。
2. **5 秒跨设备激活（`PPF2:...` 配置码）**：在第一台电脑配好飞书连接后，点击插件设置页「📤 复制含密钥完整迁移码」，到第二台电脑粘贴即可一键同步全部表结构映射。
3. **兼容 NAS 未同步场景（云端兜底文案）**：当 NAS 上的成品文件夹尚未同步到另一台电脑时，点击飞书「🚀 去发布」按钮**不会报错阻断**，而是自动切换为云端关联模式，从飞书多维表的 `[发布包快照]` 列（或 `[通用标题]` + `[通用文案]` 列）自动拉取文案填入面板。

> **合规与安全边界**：本工具只做「飞书多维表同步 + 本地目录定位 + 正常打开创作者网页 + 向网页输入框拟人预填草稿」，不伪造任何创作者平台接口请求、不代传正片视频、绝不自动点「发布」，100% 符合各平台创作者规范。

## 一、连接飞书多维表格 & 跨设备迁移（推荐）

1. 点击浏览器右上角插件图标 → **「⚙️ 飞书直连与跨设备配置码设置」**。
2. 支持两种鉴权模式（任选其一）：
   - **个人零门槛模式（Personal Base Token）**：打开飞书多维表格右上角 `...` →「高级设置 / 插件」→「自定义授权码」，复制 `pt-...` 填入即可；
   - **团队标准模式（飞书自建应用）**：填入 `App ID` 与 `App Secret`（开通 `bitable:app` 权限，并在多维表右上角 `...` →「更多」→「添加文档应用」把该应用拉入协作者）。
3. 粘贴你的多维表格浏览器链接，点击 **「🔍 测试连接并自动探测表结构」**，插件会自动探测「多表矩阵模式（账号表 + 内容表 + 发布记录表）」或「极简单表模式」，并支持 **「☁️ 一键在内容表创建『发布包快照』云端兜底列」**。
4. **跨电脑复用**：点击 **「🔑 复制含密钥完整迁移码」**（以 `PPF2:` 开头），在新电脑插件面板顶部点击 **「📥 粘贴配置码秒连」** 即可 5 秒完成配置！

## 三、飞书多维表格公式配置（直接复制可用）

### 1. 【推荐】在「C 发布记录表」新建一键发布调度按钮（支持本地目录 + 云端兜底双兼容）

如果你的「发布记录表」通过关联字段绑定了「内容运营表」，且表内已有 **`[分发账号]`** 字段（格式如 `抖音·靖蜀黍`、`视频号·靖蜀黍.`、`小红书·万物皆有数`）：

- **第 1 步**：在「C 发布记录表」新建一列 **「查找引用（Lookup）」** 字段，命名为 **`本地作品目录`**，配置为：引用 **`内容运营表`** 的 **`本地作品目录`** 字段。
- **第 2 步**：新建一列 **「公式」** 字段（例如命名为 `一键去发布`），粘贴以下公式（带上 `&cid=" & RECORD_ID()` 后，哪怕 NAS 尚未同步目录到这台电脑，也能精准绑定该行排期并自动拉取云端兜底文案！）：

```excel
HYPERLINK(
  "http://127.0.0.1:8765/open?dir=" & ENCODEURL([本地作品目录]&"") & "&account=" & ENCODEURL([分发账号]&"") & "&cno=" & ENCODEURL([发布编号]&""),
  "🚀 去发布 · " & ([分发账号]&"")
)
```

### 2. 在「B 内容运营表」新建一键在线审片按钮（直连 Cutcheck 线上版 · 免手动选文件）

在「B 内容运营表」新建一列 **「公式」** 字段（如 `在线审片`），粘贴以下公式即可点击自动按正片命名与最大 `vN` 版本号定位本机最新成片，并通过插件本机回环流无感装入 `https://cutcheck-alpha.vercel.app/`（0 字节上传外网，同时自动带入项目名称、版本号与本机真实路径）：

```excel
IF(
  ISBLANK([本地作品目录]),
  "",
  HYPERLINK(
    "http://127.0.0.1:8765/review?dir=" & ENCODEURL([本地作品目录]&"") & "&project=" & ENCODEURL([选题方向]&"") & "&bid=" & ENCODEURL(RECORD_ID()),
    "🎬 在线审片"
  )
)
```

> **效果**：同一条作品在发布表拆成 4 行分发记录时，点「🚀 去发布 · 抖音·靖蜀黍」：若本机已有文件夹，自动打开抖音上传页 + Finder 高亮视频 + 插件预载文案与封面；若换到另一台 NAS 尚未同步完的电脑，自动跳过 Finder、打开抖音上传页并从飞书拉取云端备份文案！

---

### 2. 在「B 内容运营表」仅打开本地作品文件夹

在「内容运营表」中直接根据 **`[本地作品目录]`**（如 `20261016_特斯拉飞行汽车短视频`）打开本地 Finder 并同步插件缓存（不跳转任何平台网页）：

```excel
IF(
  LEN([本地作品目录]&"") = 0,
  "",
  HYPERLINK(
    "http://127.0.0.1:8765/open?path=" & ENCODEURL([本地作品目录]&""),
    "📂 打开文件夹"
  )
)
```

### 3. 固定平台按钮写法（无「分发账号」列时使用）

如果某张表没有 `[分发账号]` 字段，也可以直接用 `&site=` 指定平台：

- **📕 发小红书**：`HYPERLINK("http://127.0.0.1:8765/open?dir=" & ENCODEURL([本地作品目录]&"") & "&site=xhs", "📕 发小红书")`
- **💚 发视频号**：`HYPERLINK("http://127.0.0.1:8765/open?dir=" & ENCODEURL([本地作品目录]&"") & "&site=wx", "💚 发视频号")`
- **🎵 发抖音**：`HYPERLINK("http://127.0.0.1:8765/open?dir=" & ENCODEURL([本地作品目录]&"") & "&site=dy", "🎵 发抖音")`
- **📺 发 B 站**：`HYPERLINK("http://127.0.0.1:8765/open?dir=" & ENCODEURL([本地作品目录]&"") & "&site=bili", "📺 发B站")`
- **🚀 四端齐开**：`HYPERLINK("http://127.0.0.1:8765/open?dir=" & ENCODEURL([本地作品目录]&"") & "&site=all", "🚀 四平台齐发")`

## 三、`分发账号` 智能识别规则与 URL 参数表

### 1. `account`（分发账号）自动识别映射表

| 飞书 `[分发账号]` 示例值 | 自动识别平台 (`site`) | 自动打开的创作者后台 URL（原生新标签页打开，零 Referer 痕迹） | 品牌目录提示 |
|---|---|---|---|
| `抖音·靖蜀黍` | `dy`（抖音） | `https://creator.douyin.com/creator-micro/content/upload` | 优先匹配 `靖蜀黍` |
| `视频号·靖蜀黍.`（自动清掉末尾 `.`） | `wx`（微信视频号） | `https://channels.weixin.qq.com/platform/post/list` | 优先匹配 `靖蜀黍` |
| `小红书·万物皆有数` | `xhs`（小红书） | `https://creator.xiaohongshu.com/publish/publish?source=official&from=menu&target=video` | 优先匹配 `万物有数` |
| `B站·靖蜀黍` / `哔哩哔哩·万物有数` | `bili`（B 站） | `https://member.bilibili.com/platform/upload/video/frame` | 按账号后缀匹配 |
| `快手·xxx` / `公众号·xxx` / `知乎·xxx` / `YouTube·xxx` | `ks` / `mp` / `zhihu` / `yt` | 对应官方创作者后台 | 按账号后缀匹配 |

### 2. `/open` 接口参数一览

| 参数名 | 必填 | 说明 |
|---|---|---|
| `dir`（或 `path`） | 是 | 纯作品目录名（如 `20261016_特斯拉飞行汽车短视频`）或相对于 `workspaceRoot` 的相对路径（严禁 `..` 越界） |
| `account`（或 `acct`） | 否 | 飞书「分发账号」原始文本（如 `抖音·靖蜀黍`、`视频号·靖蜀黍.`）；未传且未传 `site` 时仅打开本地 Finder |
| `site` | 否 | 显式平台短码：`xhs` / `wx` / `dy` / `bili` / `ks` / `mp` / `zhihu` / `yt` / `all`（四端齐开）/ `finder`（仅打开 Finder） |
| `pack` | 否 | 可选指定成品包子目录名；省略时自动按 `成片` → `04_成片` → `04_发布与成片` → `09_发布与交付` 探测 |
| `finder` | 否 | 默认为 `1`（打开 Finder 并高亮选中主视频）；传 `finder=0` 时仅透传插件并打开网页 |

## 四、飞书「引用选项」动态状态列兼容与原生自动化流转配法（推荐）

如果你的「发布记录表」中的 `状态` 列使用了飞书多维表格的**「引用选项（从其他数据表引用单选项）」**功能，飞书 Bitable v1 接口（如使用个人授权码 `pt-...` 或仅开通 `bitable:app` 权限时）会拒绝外部 API 直接改写单选引用列（原报错 `1254062: SingleSelectFieldConvFail`）。

**v2.0.3 起已内置三级无感自愈**：遇到 `1254062` 时插件会自动剥离单选状态列并记住表特征，**100% 确保 `计划发布时间`、`真实发布日期`、`标题`、`正文`、`话题标签` 与关联作品落表成功**（你也可以在插件飞书设置页直接切换为「⚡ 仅写发布时间与文案，状态交由飞书自动化流转」实现 1 次请求极速直通）。

配合飞书多维表格右上角 **「⚡ 自动化」+ 公式列 `NOW()` 动态对比**（一劳永逸，免去中间状态切换）：

1. **自动化规则（填入真实发布日期自动流转 `C21已发布`）**
   - **触发条件（修改记录）**：当 `C 发布记录表` 的 `真实发布日期` 不为空（且 `状态` 不含 `C21/C22/C23/C24`）
   - **执行操作**：修改记录 → 将 `状态` 直接设为 `C21已发布`（进而自动联动 B 表全渠道完结收口为 `B21已完成`）
2. **`发布窗口建议` 公式列（统一只用 `真实发布日期` 实时对比 `NOW()`，无需 `计划发布时间` 列）**
   - 当 `[真实发布日期] > NOW()` 时自动显示 `⏳ 已定时发布 (MM-DD HH:mm)`；到达发布时刻后无需人工干预，自动变为 `✅ 已发布 (MM-DD HH:mm)`。
