# 飞书多维表格 → Finder 定位视频 + 透传插件 + 唤起发布页 配置指南

通过本地轻量 Python 服务（`127.0.0.1:8765`），实现在飞书多维表格里**点一下超链接**，0.4 秒内同步完成三件事：
1. **唤起 macOS Finder 并自动高亮选中主视频文件（`open -R`）**：你鼠标直接按住高亮的 `.mp4` 拖进浏览器即可上传；
2. **自动将成品包（`publish.pack.json` 或 `发布包_v01.md` + 全部封面/轮播图）透传进浏览器插件**：连拖成品包文件夹的步骤都省了（同时你仍可随时手动拖目录覆盖）；
3. **自动打开目标创作者后台页面**（小红书、视频号、抖音、B站，甚至一键四端齐开）。

> **合规与安全边界**：本地服务只做「唤起本地 Finder + 正常打开网页 + 向插件本地存储预载草稿」，不伪造任何平台请求、不代传视频、不自动点发布，100% 符合各平台创作者规范。

## 一、10 秒开启本机后台常驻服务（配置一次，开机自启）

在项目根目录执行：

```bash
# 可选：自定义你的工作空间根目录（未创建时默认自动使用 ~/Desktop/AIHub）
cat > .bridge.local.json << 'EOF'
{
  "workspaceRoot": "~/Desktop/AIHub",
  "port": 8765,
  "packSubdirs": ["成片", "04_发布与成片", "09_发布与交付", "publish_pack"]
}
EOF

# 注册为 macOS 登录自启后台服务（零终端黑框，静默常驻）
./scripts/macos_service.sh install
```

（不想开机自启的话，也可以平时双击根目录的 `启动本地桥接.command` 临时运行。）

## 二、飞书多维表格公式模板（直接复制可用）

假设你的飞书多维表格中有一列文本字段叫 **`[相对路径]`**，存的是相对于 `workspaceRoot` 的作品路径（例如：`2 AH领域·Areas/2026_万物有数/04_作品/20261117_天津城市变迁`）。

### 场景 A：成品包位于固定子目录（如 `成片/` 或 `09_发布与交付/`，服务自动探测拼接）

新建「公式」列，直接粘贴对应平台的公式：

- **📕 打开成品包 · 小红书**
  ```excel
  HYPERLINK("http://127.0.0.1:8765/open?path=" & ENCODEURL([相对路径]) & "&site=xhs", "📕 发小红书")
  ```
- **💚 打开成品包 · 微信视频号**
  ```excel
  HYPERLINK("http://127.0.0.1:8765/open?path=" & ENCODEURL([相对路径]) & "&site=wx", "💚 发视频号")
  ```
- **🎵 打开成品包 · 抖音**
  ```excel
  HYPERLINK("http://127.0.0.1:8765/open?path=" & ENCODEURL([相对路径]) & "&site=dy", "🎵 发抖音")
  ```
- **📺 打开成品包 · B 站**
  ```excel
  HYPERLINK("http://127.0.0.1:8765/open?path=" & ENCODEURL([相对路径]) & "&site=bili", "📺 发B站")
  ```
- **🚀 一键四端齐开（同时打开小红书+视频号+抖音+B站 + 弹出 Finder）**
  ```excel
  HYPERLINK("http://127.0.0.1:8765/open?path=" & ENCODEURL([相对路径]) & "&site=all", "🚀 四平台齐发")
  ```
- **📂 仅在 Finder 定位文件并更新插件缓存（不新开平台网页）**
  ```excel
  HYPERLINK("http://127.0.0.1:8765/open?path=" & ENCODEURL([相对路径]) & "&site=finder", "📂 打开本地目录")
  ```

---

### 场景 B：不同记录的成品包子目录不固定（额外带 `[成品包相对路径]` 字段）

如果表格里单独建了一列可选字段 **`[成品包相对路径]`**（例如填 `成片`、`v2交付` 或留空走默认探测），公式写法：

```excel
HYPERLINK(
  "http://127.0.0.1:8765/open?path=" & ENCODEURL([相对路径]) & "&pack=" & ENCODEURL([成品包相对路径]) & "&site=xhs",
  "打开成品包 · 小红书"
)
```

## 三、URL 参数速查表

| 参数名 | 必填 | 说明与可选值 |
|---|---|---|
| `path` | 是 | 相对于 `workspaceRoot` 的作品目录或成品包目录路径（服务端已做严格沙箱校验，禁止 `..` 越界访问） |
| `pack` | 否 | 成品包相对子路径（相对于该作品目录或相对于 `workspaceRoot`）；省略时自动按 `成片` → `04_发布与成片` → `09_发布与交付` 顺序探测 |
| `site` | 否 | `xhs`（小红书，默认）、`wx`（视频号）、`dy`（抖音）、`bili`（B站）、`ks`（快手）、`mp`（公众号）、`all`（四端齐开）、`finder`（仅打开目录与同步插件） |
| `finder` | 否 | 默认为 `1`（打开 Finder 并高亮 `.mp4` 主视频）；传 `finder=0` 时只同步插件并跳网页、不弹 Finder（12 秒内连续点击同一作品的不同平台会自动防抖免重复弹窗） |
