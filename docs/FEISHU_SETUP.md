通过本机回环 Python 服务（`127.0.0.1:8765`），实现在飞书多维表格里**点一下公式按钮**，0.4 秒内同步完成四件事：
1. **纯作品目录名智能转化真实路径**：飞书只需存纯目录名（如 `20261016_特斯拉飞行汽车短视频` 或 `20261117_天津城市变迁`），本地脚本自动按 **「品牌提示优先 → `2 AH领域/*/04_作品` → `1 AH项目` → `01_选题库` → `4 AH归档` → 归档挂载盘」** 三级寻址定位；
2. **「分发账号」自然语言解析与防串号提醒**：直接读取飞书里的 `抖音·靖蜀黍`、`视频号·靖蜀黍.`、`小红书·万物皆有数`，自动洗掉末尾标点噪音、匹配对应创作者发布页 URL，并在浏览器插件顶部高亮提示 **「👤 调度账号：抖音·靖蜀黍 · 请核对登录头像」** 防止发错号；
3. **唤起 macOS Finder 并自动高亮选中主视频文件（`open -R`）**：鼠标直接按住高亮的 `.mp4` / `.mov` 拖进网页上传框即可；
4. **零拖拽透传成品包与高清配图进插件**：自动读取 `成片/`、`04_成片/`、`04_发布与成片/`、`09_发布与交付/` 下的 `publish.pack.json` / `发布包_v01.md` / `发布文案*.md` 及全部封面图写入浏览器插件（同时保留随时手动拖文件夹覆盖的能力）。

> **合规与安全边界**：本地服务只做「本地路径寻址 + 唤起 Finder + 正常打开创作者网页 + 向插件本地存储预载草稿」，不伪造任何平台接口请求、不代传正片视频、绝不自动点「发布」，100% 符合各平台创作者规范。

## 二、飞书多维表格公式配置（直接复制可用）

### 1. 【推荐】在「C 发布记录表」新建一键发布调度按钮

如果你的「发布记录表」通过关联字段绑定了「内容运营表」，且表内已有 **`[分发账号]`** 字段（格式如 `抖音·靖蜀黍`、`视频号·靖蜀黍.`、`小红书·万物皆有数`）：

- **第 1 步**：在「C 发布记录表」新建一列 **「查找引用（Lookup）」** 字段，命名为 **`本地作品目录`**，配置为：引用 **`内容运营表`** 的 **`本地作品目录`** 字段。
- **第 2 步**：新建一列 **「公式」** 字段（例如命名为 `一键去发布`），直接粘贴以下公式（注意：关联/查找引用字段末尾加 `&""` 可自动转为纯文本）：

```excel
IF(
  LEN([本地作品目录]&"") = 0,
  "⚠️ 未绑本地目录",
  HYPERLINK(
    "http://127.0.0.1:8765/open?dir=" & ENCODEURL([本地作品目录]&"") & "&account=" & ENCODEURL([分发账号]&""),
    "🚀 去发布 · " & ([分发账号]&"")
  )
)
```

> **效果**：同一条作品在发布表拆成 4 行分发记录时，点「🚀 去发布 · 抖音·靖蜀黍」自动打开抖音上传页 + Finder 高亮视频 + 插件预载文案与抖音竖封/横封；12 秒内再点下一行「🚀 去发布 · 视频号·靖蜀黍.」会自动防抖免重复弹 Finder，直接打开视频号后台！

---

### 2. 在「B 内容运营表」仅打开本地作品文件夹

在「内容运营表」中直接根据 **`[本地作品目录]`**（如 `20261016_特斯拉飞行汽车短视频`）打开本地 Finder 并同步插件缓存（不跳转任何平台网页）：

```excel
IF(
  LEN([本地作品目录]&"") = 0,
  "",
  HYPERLINK(
    "http://127.0.0.1:8765/open?path=" & ENCODEURL([本地作品目录]&""),
    "📂 打开文件夹"
  )
)
```

## 三、`分发账号` 智能识别规则与 URL 参数表

### 1. `account`（分发账号）自动识别映射表

| 飞书 `[分发账号]` 示例值 | 自动识别平台 (`site`) | 自动打开的创作者后台 URL | 品牌目录提示 |
|---|---|---|---|
| `抖音·靖蜀黍` | `dy`（抖音） | `https://creator.douyin.com/creator-micro/content/upload` | 优先匹配 `靖蜀黍` |
| `视频号·靖蜀黍.`（自动清掉末尾 `.`） | `wx`（微信视频号） | `https://channels.weixin.qq.com/platform` | 优先匹配 `靖蜀黍` |
| `小红书·万物皆有数` | `xhs`（小红书） | `https://creator.xiaohongshu.com/publish/publish?source=official` | 优先匹配 `万物有数` |
| `B站·靖蜀黍` / `哔哩哔哩·万物有数` | `bili`（B 站） | `https://member.bilibili.com/platform/upload/video/frame` | 按账号后缀匹配 |
| `快手·xxx` / `公众号·xxx` / `知乎·xxx` / `YouTube·xxx` | `ks` / `mp` / `zhihu` / `yt` | 对应官方创作者后台 | 按账号后缀匹配 |

### 2. `/open` 接口参数一览

| 参数名 | 必填 | 说明 |
|---|---|---|
| `dir`（或 `path`） | 是 | 纯作品目录名（如 `20261016_特斯拉飞行汽车短视频`）或相对于 `workspaceRoot` 的相对路径（严禁 `..` 越界） |
| `account`（或 `acct`） | 否 | 飞书「分发账号」原始文本（如 `抖音·靖蜀黍`、`视频号·靖蜀黍.`）；未传且未传 `site` 时仅打开本地 Finder |
| `site` | 否 | 显式平台短码：`xhs` / `wx` / `dy` / `bili` / `ks` / `mp` / `zhihu` / `yt` / `all`（四端齐开）/ `finder`（仅打开 Finder） |
| `pack` | 否 | 可选指定成品包子目录名；省略时自动按 `成片` → `04_成片` → `04_发布与成片` → `09_发布与交付` 探测 |
| `finder` | 否 | 默认为 `1`（打开 Finder 并高亮选中主视频）；传 `finder=0` 时仅透传插件并打开网页 |
